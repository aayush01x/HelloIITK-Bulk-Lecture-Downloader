# Hello IITK Bulk Lecture Downloader

A simple and lightweight Tampermonkey userscript to bulk download all lectures in the Lectures tab of the Hello IITK Portal.

### Installation
- Install Tampermonkey extension for your browser.
- Create New Script: Open the Tampermonkey Dashboard and click the + (plus) icon.
- Paste the Code: Copy the contents of `BulkDownloader.user.js` from this repo and paste it into the editor.
- Save: Press Ctrl + S or File > Save.

### How to Use
- Open the Lectures tab of the course, and a blue button labelled "Download All Lectures" will appear in the top right.
